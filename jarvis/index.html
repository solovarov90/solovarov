Подписка Claude, Python на компьютере и аккаунт Telegram. Для круглосуточной работы — сервер от 500 ₽ в месяц, но можно и на своём компьютере, пока он включён.

Почему без API-ключей?

Бот обращается к Claude Code, в который ты вошёл по своей подписке. Отдельно за API платить не нужно.
